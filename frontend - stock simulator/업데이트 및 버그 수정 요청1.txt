# NIGHT MARKET 업데이트 및 버그 수정 요청

현재 개발된 NIGHT MARKET 주식 투자 게임을 기반으로 아래 기능들을 개선해 줘.

**중요: 기존에 구현한 기능과 디자인을 최대한 유지해 줘. 프로젝트를 처음부터 다시 만들거나 기존 기능을 임의로 삭제하지 말고, 현재 코드 구조를 먼저 분석한 뒤 필요한 부분만 수정해 줘.**

이번 업데이트의 핵심은 주가 변동의 재미를 높이고, 정보 구매 시스템을 개선하며, 뉴스와 힌트가 여러 라운드에 걸쳐 연속성을 갖도록 만드는 것이다.

---

## 1. 주식 상승폭과 하락폭 확대

현재 주식의 상승폭과 하락폭이 다소 작아서 투자하는 재미가 부족하다.

전체적인 주식의 가격 변동폭을 지금보다 크게 조정해 줘.

### 변경 방향

- 일반 주식의 기본 변동폭을 기존보다 확대.
- 이벤트가 발생했을 때 관련 기업의 상승 및 하락 폭을 더욱 크게 설정.
- 기업별 개별 호재 및 악재의 영향력도 확대.
- 긍정적인 이벤트와 부정적인 이벤트의 영향이 확실하게 체감되도록 변경.
- 정민코인은 기존처럼 일반 주식보다 훨씬 높은 변동성을 유지.

권장 변동폭은 다음과 같이 설정해 줘.

| 구분 | 권장 변동폭 |
|---|---|
| 일반적인 시장 변동 | -10% ~ +10% |
| 기업별 호재 및 악재 | 추가 ±5~15% |
| 강력한 이벤트 | 추가 ±10~20% |
| 일반 주식 최대 변동폭 | 약 ±40% |
| 정민코인 | 기존의 높은 변동성 유지 |

위 수치는 기본 설계 기준이며 실제 변동률 계산 시 기존 이벤트 효과와 기업별 특성이 반영되도록 해 줘.

단순히 모든 기업의 변동률을 똑같이 높이지 말고, 산업 분야별 특성을 살려 줘.

예를 들어 바이오 기업의 임상시험 실패는 일반적인 시장 악재보다 더 큰 하락을 발생시킬 수 있고, 신약 개발 성공은 큰 상승을 유발할 수 있어야 한다.

단, 상승과 하락의 확률 및 크기는 어느 정도 균형을 유지해야 한다.

## 2. 정보코인 여러 개 동시 구매

현재 정보코인을 한 번에 하나씩만 구매할 수 있는데, 여러 개를 한꺼번에 구매할 수 있도록 개선해 줘.

### 변경 사항

- 정보코인 구매 수량을 직접 입력할 수 있도록 변경.
- +1, +5, +10 버튼 추가.
- 원하는 수량을 직접 입력하는 기능 추가.
- 구매할 정보코인의 총가격 실시간 표시.
- 구매 확정 버튼 추가.
- 보유 현금이 부족하다면 구매 불가능하도록 처리.

기존 정보코인 가격 규칙인 현재 보유 현금의 5%를 1개 가격으로 적용하는 규칙은 유지해 줘.

여러 개를 동시에 구매할 때도 기존의 순차 가격 계산 방식을 유지해야 해. 즉, 첫 번째 코인을 구매한 후 남은 현금을 기준으로 두 번째 코인의 가격을 계산하는 방식이야.

구매 전에 예상 총가격을 미리 계산해서 보여 줘.

구매 후에는 현금과 정보코인 잔액이 정확하게 갱신되어야 해.

## 3. 초기 주식 가격 다양화

현재 7개 기업의 초기 주가가 지나치게 비슷하다면 수정해 줘.

각 기업의 초기 상장 가격을 서로 다르게 설정해 줘.

다음 가격을 초기 설정값으로 사용해 줘.

| 회사명 | 분야 | 초기 주가 |
|---|---|---:|
| 바이오웨이브 | 바이오·제약 | 8,500원 |
| 달콤제과 | 베이커리·식품 | 3,200원 |
| 넥스트칩 | 반도체·AI | 42,000원 |
| 그린펄스 | 신재생에너지 | 12,500원 |
| 플레이온 | 엔터테인먼트 | 27,000원 |
| 로드링크 | 물류·운송 | 6,800원 |
| 스카이실드 | 방산·항공우주 | 75,000원 |

저렴한 주식부터 비싼 주식까지 다양하게 분포하도록 해 줘.

주식 가격이 다르더라도 각 기업의 상승률과 하락률 계산은 동일한 원칙을 사용해야 해.

## 4. 주식 구매 수량 조절 기능 개선

현재 주식 구매 화면에서 수량을 늘릴 때 보유 현금보다 비싼 금액이 되어도 수량이 계속 증가하는 문제가 있다.

이 부분을 수정해 줘.

### 구매 수량 조절 버튼

매수 화면에 다음 버튼을 추가해 줘.

- `-1` : 구매 수량 1개 감소.
- `+1` : 구매 수량 1개 증가.
- `+5` : 구매 수량 5개 증가.
- `+10` : 구매 수량 10개 증가.
- `전체선택` : 현재 보유 현금으로 구매 가능한 최대 수량 자동 설정.

수량을 늘릴 때마다 다음 사항을 확인해야 해.

1. 현재 보유 현금 확인.
2. 주식 1주 가격 확인.
3. 선택한 구매 수량의 총가격 계산.
4. 구매 총액이 보유 현금을 초과하지 않는지 확인.

**핵심 규칙: 보유 현금으로 구매할 수 있는 최대 수량에 도달하면 더 이상 수량이 증가하지 않아야 한다.**

예를 들어 현금이 100,000원이고 주식 가격이 10,000원이라면 최대 10주까지만 선택할 수 있어야 해.

현재 8주를 선택한 상태에서 +5를 눌렀을 때 13주가 아니라 최대 구매 가능한 10주까지만 증가해야 해.

전체선택 버튼을 누르면 정확히 최대 구매 가능 수량이 설정되어야 한다.

수량 입력창에 직접 숫자를 입력하는 경우에도 최대 구매 가능 수량을 초과하지 않도록 처리해 줘.

구매 버튼을 누르기 직전에도 최종적으로 자금 부족 여부를 검사해 줘.

매도 화면에도 비슷한 수량 조절 기능을 적용하되, 보유 주식 수량 이상으로 매도 수량을 설정할 수 없도록 해 줘.

## 5. 미드나잇 코인 이름 변경

기존에 사용하던 '미드나잇 코인'이라는 명칭을 전부 '정민코인'으로 변경해 줘.

게임 화면뿐만 아니라 다음 부분도 모두 확인해 줘.

- 주식 거래 화면.
- 자산 현황.
- 주가 그래프.
- 뉴스 센터.
- 아이템 효과 설명.
- 게임 종료 결과.
- 주식 관련 데이터.
- 관련 안내 문구.

기존 코인의 가격 변동 시스템과 독립적인 랜덤 변동 규칙은 그대로 유지해야 해.

이름만 변경하고 기존 정민코인의 변동 특성을 훼손하지 말아 줘.

## 6. 정민코인 전용 그래프 추가

정민코인의 가격 변동을 확인할 수 있는 그래프를 추가해 줘.

정민코인을 선택하면 전용 상세 화면이 나타나도록 해 줘.

다음 정보를 표시해 줘.

- 현재 정민코인 가격.
- 이전 라운드 대비 변동률.
- 현재 보유 수량.
- 정민코인 총평가액.
- 역대 가격 변동 그래프.
- 최고 가격.
- 최저 가격.

그래프는 라운드별 가격을 표시하는 선 그래프로 만들어 줘.

1라운드부터 현재 라운드까지의 가격 변동을 한눈에 확인할 수 있어야 해.

상승 구간과 하락 구간은 구분되는 색상으로 표시해 줘.

정민코인의 가격 변동 이력은 게임 진행 중 계속 저장되어야 하고, 새로고침 후에도 그래프가 유지되어야 해.

## 7. 정보코인 구매 위치 변경

현재 정보코인을 정보국에 들어가서 구매해야 하는 구조라면 이를 변경해 줘.

정보코인 구매 기능을 정보국에서 분리해 줘.

컴퓨터 바탕화면 또는 주식 거래 프로그램의 별도 영역에 '정보코인 구매' 메뉴를 만들어 줘.

추천 UI 구성:

- 주식 거래
- 정보코인 구매
- 정보국
- 뉴스패드
- 아이템 보관함
- 자산 현황

정보코인 구매 메뉴에 들어가면 코인 가격, 보유 수량, 구매 수량, 총가격이 표시되어야 해.

정보국은 정보코인을 사용하여 힌트를 구매하고 확인하는 공간으로 유지해 줘.

정보코인 구매와 힌트 구매의 역할이 명확하게 구분되어야 해.

## 8. 라운드 종료 시 주가 변동 이유 확인 기능

현재 라운드가 종료되면 각 회사의 주가 상승 및 하락 이유가 결과 화면에 표시되는데, 결과 화면을 닫거나 다음 라운드로 넘어가면 해당 정보를 다시 확인하기 어렵다.

이 문제를 수정해 줘.

라운드가 종료될 때 생성된 모든 주가 변동 이유를 뉴스패드에 자동으로 저장해 줘.

뉴스패드에서 이전 라운드를 선택하면 해당 라운드에 발생했던 모든 주식의 상승 및 하락 이유를 다시 확인할 수 있어야 해.

예를 들어 3라운드가 종료되었다면 다음 정보를 확인할 수 있어야 해.

- 바이오웨이브 상승 이유.
- 달콤제과 하락 이유.
- 넥스트칩 상승 이유.
- 그린펄스 상승 이유.
- 플레이온 하락 이유.
- 로드링크 상승 이유.
- 스카이실드 하락 이유.
- 정민코인 가격 변동 내역.

결과 화면에서만 볼 수 있는 일회성 데이터가 아니라 게임 기록에 영구적으로 저장되는 데이터로 처리해 줘.

## 9. 뉴스와 힌트의 내용 다양화

현재 뉴스피드와 정보국에서 제공하는 힌트의 내용이 지나치게 비슷하다.

이 부분을 대폭 개선해 줘.

뉴스와 힌트는 서로 다른 목적과 성격을 가지고 있어야 해.

### 뉴스피드의 역할

뉴스피드는 시장에서 실제로 발생한 사건이나 공개된 기업 정보를 전달하는 역할이야.

예시:

- 신제품 출시.
- 기업의 대규모 계약 체결.
- 경영진 교체.
- 해외 진출.
- 정부 규제 발표.
- 경쟁 업체의 기술 개발.
- 공장 화재.
- 대규모 투자 유치.
- 소비자 불매 운동.
- 기업의 실적 발표.
- 해외 시장의 수요 변화.
- 원자재 가격 급등.

뉴스는 기업과 산업에 대한 다양한 사건을 전달해야 해.

### 정보국 힌트의 역할

힌트는 공개 뉴스와 다른 성격을 가져야 해.

단순히 뉴스 문장을 조금 바꿔서 제공하지 말아 줘.

힌트는 플레이어가 기업의 상황을 해석하고 향후 주가를 예측할 수 있도록 제공되는 추가 정보야.

예를 들어 다음과 같은 식으로 만들어 줘.

**하급 힌트**
- 최근 특정 기업의 연구개발팀에서 야근이 늘어났다는 이야기가 들린다.
- 일부 유통업체가 특정 제품의 주문량을 조정하고 있다는 소식이 있다.
- 한 기업의 핵심 인력이 외부 업체와 접촉했다는 이야기가 들려온다.
- 특정 산업의 원자재 재고가 평소보다 빠르게 소진되고 있다.

**중급 힌트**
- 한 기업의 제품 재고가 예상보다 빠르게 소진되고 있지만, 생산 설비의 가동률은 오히려 감소했다.
- 일부 투자자들이 특정 기업의 실적 발표를 앞두고 보유 주식을 정리하고 있다는 분석이 나온다.
- 해외 거래처에서 대규모 주문이 접수되었지만 납품 일정에 차질이 생겼다는 이야기가 있다.
- 특정 기업의 기술 개발 성과가 기대 이상이라는 평가가 있지만 상용화 여부는 불확실하다.

**상급 힌트**
- 내부 테스트 결과 신제품의 결함률이 크게 낮아졌으며, 주요 유통사와의 계약도 사실상 확정된 것으로 알려졌다.
- 핵심 서버의 장애로 주요 데이터가 복구 불가능한 상태이며, 기업 내부에서도 피해 규모를 파악하지 못하고 있다.
- 해외 대형 고객사가 장기 공급 계약을 체결하기로 결정했으며, 다음 실적 발표에 반영될 가능성이 높다.
- 핵심 연구진이 대거 이탈하면서 현재 진행 중인 신약 개발 일정에 심각한 차질이 발생할 것으로 예상된다.

이처럼 단순히 좋다거나 나쁘다는 표현이 아니라, 정보를 읽고 상황을 추론할 수 있는 복합적인 힌트를 만들어 줘.

### 힌트 다양성 규칙

- 각 기업마다 최소 15~20개 이상의 서로 다른 힌트 소재를 준비해 줘.
- 하급, 중급, 상급별로 별도의 힌트 데이터 풀을 구성해 줘.
- 같은 문장이 반복해서 나오지 않도록 해 줘.
- 기업의 산업 특성에 맞는 정보를 제공해 줘.
- 긍정적인 정보, 부정적인 정보, 중립적인 정보 모두 준비해 줘.
- 정보의 일부가 서로 모순되거나 불확실한 상황도 포함해 줘.
- 한 가지 정보만 보고 무조건적인 정답을 알 수 없도록 설계해 줘.
- 힌트는 실제 주가 변동에 사용되는 숨겨진 정보와 연결되어야 해.

하급 힌트는 해석이 어려워야 하고, 중급은 어느 정도 방향을 파악할 수 있으며, 상급은 투자 판단에 상당한 도움을 줄 수 있어야 해.

## 10. 라운드마다 다양한 힌트를 랜덤 제공

현재 힌트가 지나치게 정해진 문장 위주로 제공된다면 개선해 줘.

플레이어가 힌트를 구매할 때마다 해당 기업과 등급에 맞는 여러 가지 힌트 중에서 랜덤으로 하나를 제공해 줘.

예를 들어 바이오웨이브의 하급 힌트를 구매한다면 바이오 분야에 관련된 여러 힌트 중 하나를 랜덤으로 보여 주는 방식이야.

동일한 라운드에서 같은 힌트를 반복 구매했을 때는 가능한 한 이미 제공한 힌트가 다시 나오지 않도록 해 줘.

단순히 무작위 문장을 선택하는 것이 아니라, 해당 라운드에 설정된 실제 기업의 상황과 일치하는 힌트를 제공해야 해.

**매우 중요한 사항**

힌트를 랜덤으로 보여 주더라도 실제 주가 변동 로직과 연결되어 있어야 해.

예를 들어 실제로 기업에 악재가 설정되어 있는데 긍정적인 결과만 예상하게 만드는 힌트가 나오면 안 돼.

다만 정보의 해석이 어려운 하급 힌트에서는 중립적이거나 상반된 요소가 섞여 있을 수 있어.

## 11. 한 라운드에 여러 회사의 뉴스 발생

현재 한 라운드에 뉴스가 한 가지 정도만 발생하는 구조라면 개선해 줘.

한 라운드에 여러 기업에 대한 뉴스가 동시에 발생할 수 있도록 변경해 줘.

예를 들어 4라운드가 시작된다면 다음과 같이 다양한 뉴스가 등장할 수 있어.

**속보 1 - 바이오웨이브**
- 해외 바이오 기업과 공동 연구 계약을 체결했다.

**속보 2 - 달콤제과**
- 신제품에 대한 소비자 평가가 엇갈리고 있다.

**속보 3 - 넥스트칩**
- 주요 반도체 생산 시설의 가동률이 감소했다.

**속보 4 - 로드링크**
- 대형 유통업체와 장기 물류 계약을 체결했다.

**속보 5 - 스카이실드**
- 해외 방산 시장에서 신규 수출 계약 가능성이 제기되었다.

한 라운드에 여러 개의 뉴스가 발생할 수 있게 해 줘.

뉴스는 다음과 같이 구분해 줘.

- 시장 전체에 영향을 주는 뉴스.
- 특정 산업에 영향을 주는 뉴스.
- 특정 기업에만 영향을 주는 뉴스.
- 기업과 직접 관련 없는 중립적인 뉴스.

매 라운드 최소 2~5개 정도의 서로 다른 뉴스가 발생하도록 해 줘.

단, 모든 뉴스가 반드시 주가에 영향을 주어야 하는 것은 아니야.

단순한 시장 동향이나 중립적인 정보도 포함해 줘.

뉴스가 많아져도 실제 주가 변동은 각 뉴스의 영향력을 종합해서 계산해야 해.

동일한 기업에 긍정적인 뉴스와 부정적인 뉴스가 동시에 발생할 수도 있어야 해.

이 경우 두 뉴스의 영향이 서로 상쇄되거나 한쪽의 영향이 더 크게 나타날 수 있도록 만들어 줘.

## 12. 이전 라운드 뉴스가 이후 라운드에 영향을 주는 연속성 시스템

이 부분은 이번 업데이트에서 특히 중요해.

현재는 이전 라운드에서 발생한 뉴스가 다음 라운드에 제대로 영향을 미치지 않는 것 같아.

뉴스와 기업의 상황에 지속성이 생기도록 변경해 줘.

예를 들어 다음과 같은 상황이야.

**2라운드**
- 넥스트칩의 주요 서버에서 대규모 데이터 유출 사고가 발생했다.

**3라운드**
- 데이터 유출 사고에 대한 피해 규모가 예상보다 크다는 분석이 나왔다.
- 주요 거래처들이 계약 재검토에 들어갔다.

**4라운드**
- 넥스트칩이 보안 시스템 교체에 대규모 자금을 투입하기로 결정했다.

이처럼 하나의 사건이 여러 라운드에 걸쳐 발전할 수 있어야 해.

### 연속성 구현 규칙

- 이전 라운드에 발생한 일부 뉴스는 다음 라운드에 영향을 줄 수 있어야 한다.
- 모든 뉴스가 영구적으로 영향을 주는 것은 아니며 뉴스별 지속 기간을 설정한다.
- 뉴스에 지속 효과, 즉시 효과, 일회성 효과를 구분한다.
- 하나의 사건이 이후 라운드에 후속 뉴스로 발전할 수 있어야 한다.
- 이전 사건이 해결되거나 악화되는 후속 상황도 등장할 수 있어야 한다.
- 해결된 사건은 더 이상 주가에 영향을 주지 않도록 한다.
- 같은 사건이 이유 없이 무한 반복되지 않도록 관리한다.

예를 들어:

| 사건 | 영향 지속 기간 |
|---|---|
| 단기 신제품 인기 | 1~2라운드 |
| 대형 계약 체결 | 2~3라운드 |
| 기업 데이터 유출 | 2~4라운드 |
| 국제 분쟁 확대 | 2~4라운드 |
| 장기 정부 지원 정책 | 3~5라운드 |
| 공장 화재 | 복구 상황에 따라 변화 |

지속 기간은 사건마다 다르게 설정해 줘.

특히 이전 라운드의 뉴스가 단순히 다시 등장하는 것이 아니라, 새로운 상황이나 후속 정보로 이어지도록 만들어 줘.

## 13. 뉴스패드와 정보국의 이전 기록 표시 오류 수정

현재 뉴스패드와 정보국에서 이전 라운드에 구매하거나 공개했던 뉴스와 힌트가 제대로 표시되지 않는 문제가 있어.

이 부분을 확실하게 수정해 줘.

### 뉴스패드

뉴스패드에서는 지금까지 발생했던 모든 뉴스와 주가 변동 이유를 확인할 수 있어야 해.

- 현재 라운드 뉴스.
- 이전 라운드 뉴스.
- 과거 라운드에 발생한 기업별 속보.
- 뉴스의 후속 보도.
- 라운드 종료 후 생성된 주가 변동 원인.

라운드별로 구분하여 볼 수 있도록 해 줘.

### 정보국

정보국에서도 이전에 구매한 힌트를 모두 확인할 수 있어야 해.

각 힌트에는 다음 정보가 표시되어야 해.

- 힌트를 구매한 라운드.
- 대상 기업.
- 힌트 등급.
- 힌트 내용.
- 구매 가격.
- 구매 시점.

이전 라운드에 구매한 힌트가 다음 라운드로 넘어가더라도 사라지면 안 돼.

힌트는 구매 시점의 내용을 그대로 저장해서 보여 줘야 해.

나중에 기업의 상황이 바뀌더라도 과거에 구매한 힌트 내용이 바뀌면 안 돼.

### 데이터 저장 관련 주의사항

현재 게임 상태를 저장하는 localStorage 또는 기존 상태 관리 구조를 확인해 줘.

뉴스와 힌트가 화면에서만 임시로 생성되고 사라지는 문제가 발생하지 않도록 해 줘.

모든 뉴스와 힌트는 고유 ID, 발생 라운드, 관련 기업 등의 정보를 포함해 데이터로 보존해 줘.

새로고침 후에도 과거 기록이 정상적으로 복원되어야 해.

기존 저장 데이터와 새 데이터 구조가 충돌할 가능성이 있다면 안전하게 마이그레이션해 줘. 기존 게임 기록을 무조건 초기화하지 말아 줘.

## 14. 1라운드에도 정보 구매 가능하도록 변경

현재 1라운드에서는 이벤트가 발생하지 않아서 정보 구매가 제한되는 것 같아.

1라운드부터 정보코인 구매와 힌트 구매를 모두 가능하게 변경해 줘.

단, 기존 규칙대로 1라운드에는 랜덤 이벤트가 발생하지 않아야 해.

대신 1라운드부터 기업별 내부 정보와 시장 동향을 설정해 줘.

예를 들어:

- 바이오웨이브의 비공개 임상시험 진행 상황.
- 달콤제과의 신제품 출시 준비.
- 넥스트칩의 기술 개발 현황.
- 그린펄스의 신규 발전 사업 검토.
- 플레이온의 신규 콘텐츠 제작 상황.
- 로드링크의 물류 계약 협상.
- 스카이실드의 해외 수출 협의.

이러한 정보를 바탕으로 1라운드에도 하급, 중급, 상급 힌트를 구매할 수 있어야 해.

정보코인 구매 역시 첫 라운드부터 가능해야 해.

1라운드의 힌트도 이후 주가 변동에 실제로 연결되어야 해.

## 15. 최종 검증 사항

수정 작업이 끝나면 반드시 실제 게임을 플레이하는 상황을 가정해서 검증해 줘.

특히 아래 부분을 중점적으로 확인해 줘.

**주식 거래**
- 초기 주가가 기업별로 다르게 설정되어 있는가?
- +1, +5, +10, 전체선택 버튼이 정상적으로 작동하는가?
- 보유 현금을 초과하는 수량을 선택할 수 없는가?
- 매도 시에도 보유 수량을 초과하지 않는가?

**정보코인**
- 여러 개를 동시에 구매할 수 있는가?
- 구매 전 총가격이 정확하게 표시되는가?
- 현금이 부족할 때 구매가 차단되는가?
- 정보국과 구매 메뉴가 분리되어 있는가?

**정보국**
- 1라운드부터 힌트 구매가 가능한가?
- 하급, 중급, 상급 힌트가 충분히 다양하게 제공되는가?
- 같은 라운드에 구매할 때 여러 힌트 중 랜덤으로 제공되는가?
- 실제 주가 변동과 힌트가 연동되는가?
- 과거 구매한 힌트가 모두 남아 있는가?

**뉴스 시스템**
- 한 라운드에 여러 뉴스가 발생하는가?
- 뉴스의 내용과 주가 변동 방향이 일치하는가?
- 이전 라운드의 사건이 후속 뉴스로 이어지는가?
- 과거 뉴스와 주가 변동 이유를 언제든 확인할 수 있는가?

**정민코인**
- 미드나잇 코인이라는 명칭이 모두 정민코인으로 변경되었는가?
- 전용 그래프가 정상적으로 표시되는가?
- 과거 가격 기록이 유지되는가?
- 랜덤 변동의 독립성이 유지되는가?

**저장 기능**
- 새로고침 후 모든 뉴스와 힌트가 유지되는가?
- 거래 기록과 주가 이력이 정상적으로 남아 있는가?
- 라운드를 이동해도 과거 기록이 사라지지 않는가?

문제가 발견되면 직접 수정하고, 기존 기능이 망가진 부분이 없는지도 확인해 줘.

최종적으로 단순히 기능이 추가된 수준이 아니라, 뉴스와 힌트를 분석하고 이전 라운드의 상황을 기억하면서 투자 전략을 세울 수 있는 완성도 높은 게임으로 개선해 줘.
